# HP CONS Accounting Workspace — bản xem thử

Trang chạy thử ứng dụng Kế toán – Tài chính HP CONS. **Dữ liệu minh họa.** Toàn bộ nghiệp vụ và cơ sở dữ liệu chạy ngay trên trình duyệt; dữ liệu lưu trên máy người xem (không gửi về đâu). Chọn vai trò để thử trọn luồng duyệt chi.

Đây là bản đã đóng gói (build) để chạy trên GitHub Pages. Mã nguồn nằm ở kho riêng tư.
